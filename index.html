Google Drive koppelen

Volg deze stappen eenmalig om een gratis OAuth Client ID aan te maken.

  1. Ga naar console.cloud.google.com en log in.
  2. Maak een nieuw project aan (of kies een bestaand). Naam maakt niet uit, bijv. Lezer.
  3. Ga naar APIs & Services → Library en zoek op Google Drive API. Klik Enable.
  4. Ga naar APIs & Services → OAuth consent screen.
    Kies External, vul een app-naam in (bijv. Lezer), en sla op.
    Bij Scopes: voeg .../auth/drive.file toe.
    Bij Test users: voeg je eigen Google-e-mailadres toe.
  5. Ga naar APIs & Services → Credentials.
    Klik + Create Credentials → OAuth client ID.
    Kies als type: Web application.
    Voeg onder Authorized JavaScript origins toe: null (voor lokaal bestand) én http://localhost.
  6. Klik Create. Kopieer de Client ID (eindigt op .apps.googleusercontent.com).
  7. Klik hieronder op Client ID invoeren en plak hem in.
